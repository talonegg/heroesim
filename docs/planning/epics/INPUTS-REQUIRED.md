Everything the build needs from you that cannot be read from the design or the code, ordered by
when it is needed. Every row has a default; a row marked **blocking** stops the named story
until you answer, every other row proceeds on its default and can be changed later without

## Where this stands, 2026-09-28

The first build is complete and tagged `m8-modules`; the same commit is tagged `v1.0.0`, and work
after it continues on the v1.1 line (DL-86). Two things have been added to the baseline's tables:

- **Now** is the value in force at `m8-modules`, read from `defaultConfig` in
  `engine/src/config.ts` and from `content/*.json`, with the decision that set it. Where a row has
  no single value, it says where the values live. Where Now differs from **Default** and no
  earlier answer explains it, an agent changed the value in a story or a balance pass, and the
  named decision says why; the Default is then superseded and kept only as the baseline's history.
- **Answer** keeps the answers given before the build and adds the owner's answers from the
  interview of 2026-09-28, each marked with the decision that records it (DL-82 to DL-89) and its
  item number in the interview's agenda, as those decisions cite it. Where an answer departed from
  the agents' recommendation, the cell says so and names the recommendation. A number in
  parentheses after a DL, as in "DL-83 (item 22)", is the agenda's; one without, as in "DL-43
  item 8" or "DL-87 item 6", is the entry's own item.

The owner ratified the values in force at `m8-modules` in **DL-90** (item 62), except those that
DL-82 to DL-89 change or leave for proposals. A row marked **Ratified (DL-90)** had no other
answer: its Now is the owner's. Nothing here changes the game. A decision that changes a rule, a
content row or a config value becomes a GitHub issue and lands with its story; until then Now is
what the game plays.
