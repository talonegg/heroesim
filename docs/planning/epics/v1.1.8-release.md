# v1.1.8 — The documentation slimmed: one entry map, a decision log agents can read, and the record kept once

**Objective:** a documentation audit of 2026-10-08, made after v1.1.7's release, found that the docs
agents read to find prior context have grown faster than the game, and that a story's close now
updates the same facts in four places. This patch acts on those findings before Random Events (M10)
begins, so that M10's agents start from a slim entry map, a decision log they can read, and one place
for each fact. No play changes, and no rule changes: only documentation, generated artefacts, the
tools that write them and the checks that pin them.

The findings, with their evidence, are §5. In short:
- `docs/decision-log.md` is 2.36 MB (about 600k tokens), with 214 entries and no index, and about
  65–75% of its bytes are a record of what happened (test counts, fingerprints, verification
  narrative) rather than decisions and their reasons.
- The rules every story agent follows (where a DL entry goes, the commit format, line endings, the
  sweep rules, the story's close) live only in a session's scratchpad outside the repository, and are
  rewritten for each release. AGENTS.md never names the plan, the epics or the decision log.
- Each release is recorded in four places: the epic's Status line, `plan.md` §4, the epics README's
  register and the DL entry.
- About 535 KB of epics and reviews are closed and only history; `INPUTS-REQUIRED.md` is frozen at
  `m8-modules`; the epics README §3 still describes the v1.0 flow.
- Two generated files dominate search results: `docs/quests/calibration.json` (903 KB on one line)
  and `docs/quests/v1.1.4-review.html` (454 KB, 213 KB of matched text on a search for "Quest").

**Sessions:** 7–10 (agent's estimate) · **Depends on:** `v1.1.7` released (pull request #58, merged
as `25f8fa0`) · **Implements:** DL-215 (S3's archive, superseded items and index), and the owner's answers to the rest of §6.

**Gate:**
- *Play unchanged.* No file under `engine/src/` or `content/` changes but comments and, in S6, a
  path the editor writes; every fingerprint as it was (`neutral --expect`).
- *Nothing lost.* Every file moved keeps its full text in the repository or in a named GitHub Release
  asset; every `DL-NNN` cited anywhere in the repository resolves to one entry (S3's check); no
  relative link in `docs/`, the READMEs or `.claude/` points at a file that is gone (S1's check).
- *Every check.* `npm run lint`, `typecheck`, `test`, `e2e -w web` and check-bundle pass;
  `npm run edit -- traits doctor` reads no drift before and after S6 and at the close.
- *Smaller to read.* The documents an agent reads to start a story (AGENTS.md, the delivery guide,
  `plan.md`, the current epic, the decision log's index and open release) total under 250 KB, against
  about 2.5 MB today.
- *Verified.* Each story is verified by a second Opus agent, its findings fixed, and recorded in a DL
  entry, each after DL-215.
