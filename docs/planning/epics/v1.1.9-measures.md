# v1.1.9's measures

v1.1.9 measures before and after, the same way, with no numeric target (DL-231 Q6, Q17). This page
holds the baseline that the stories and the close measured against (DL-233), and the close's after
report (DL-252), the last section. The tables come from `npm run measure`
([`tools/measure/README.md`](../../../tools/measure/README.md)), and each run took place alone on the
owner's machine.

**Baseline:** 2026-10-09, at `07ca2f2`, `v1.1.9-dev`'s start. Its tests and code are `26cd276`'s,
before S1 moved anything. Node 26.9.0 and Vitest 5.0.2.

**After:** 2026-10-10, at `0ea6db8`, the close, on the same machine, Node and Vitest.

reports and enforces nothing (Q5).
