# v1.1.9's measures

v1.1.9 measures before and after, the same way, with no numeric target (DL-231 Q6, Q17). This page
holds the baseline that the stories and the close measure against (DL-233). S16 adds the after
column. The tables come from `npm run measure` ([`tools/measure/README.md`](../../../tools/measure/README.md)),
and each run took place alone on the owner's machine.

**Baseline:** 2026-10-09, at `07ca2f2`, `v1.1.9-dev`'s start. Its tests and code are `26cd276`'s,
before S1 moved anything. Node 26.9.0 and Vitest 5.0.2.

## Coverage

`npm run coverage` covers each package's source, without its tests or their support files. It
reports and enforces nothing (Q5).

The baseline's run had every worker and the projects' own timeouts, and 18 tests failed under V8's
instrumentation:
- 14 time-outs of 5 s or 30 s;
- the validator's time limit, at 78 ms;
- one wait of the page's Guild view;
- the citation and link checks, failing on S1's edit in progress.

`reportOnFailure` wrote the report regardless. `npm run coverage` now runs on half the workers, with
120 s a test where a test sets no timeout of its own. All 6,110 tests pass in 216 s, and the figures

  It took 413.9 s and passed `--expect 29c09fb4…d662`, identical. The shards took 131 to 281 s of
