# v1.1.6 — Deeper modules, less duplication, and tuning as checked data

**Objective:** the owner's answers of 2026-10-04 and 2026-10-05 to an architecture review of the
codebase after `v1.1.5` (DL-186), as one v1.1.x patch with no new gameplay. The review asked three
things: where modules are shallow and could be deepened, where redundancy, resource use and bloat
could be cut, and where code could become configuration for future enhancement and tuning. Its
report is the agent's, at <https://claude.ai/artifact/3dFMwTnhqVSyqB7maXvqr7>; its 16 candidates and
12 small fixes were walked through with the owner one at a time, and every one is in scope:
- *The harness proves itself.* One fold adds up a sweep's totals; one parser reads the run's
  settings; a named `gate` run checks itself against a declared spec, writes JSON beside its
  Markdown, and `compare` diffs two runs. The replay plays once and is compared with the shard that
  played the same seed. A `neutral` profile proves a play-neutral story in about 7 minutes.
- *Content and configuration as checked data.* The content version is a data file; the content
  editor changes a Trait's use in place; content may import the engine's values, so its copied
  tables go; one `playDeps` merges and checks all 121 settings before play; the tuning values move
  to a data file the editor changes, with its checks and its version raise.
- *Deeper engine modules.* Harm targeting owned by `harm.ts`; one Query operator table beside the
  evaluator; a Stat's breakdown from the engine; the engine's interface narrowed to what callers use,
  with one action dispatch, one Roster walk and one row lookup; the old content form retired; the
  write-once data kept out of the per-Turn copy (a new ADR).
- *One set of words.* A words module shared by the CLI and the page, the narration behind a Namer
  seam, so the copies that have drifted ("an offer" and "an Offer") become one.
- *The page's plumbing.* One answer to whether a Hero can go; the Party builder's rules out of the
  view; a declared Class order every list reads; the Roster's rows built apart from their sorting;
  named breakpoints; the remembered preferences in one table.
- *New tuning knobs, each defaulting to today's play.* Draw weights on Classes, Backgrounds, Quest
  templates and Spheres, a weight on a new Hero's sex, the Rivals' purchase, gear and build orders,
  and the Finale's loot degrees.

**Sessions:** 22–27 (agent's estimate) · **Depends on:** `v1.1.5` released (pull request #54,
merged as `8bca6b9`) · **Implements:** DL-186.
