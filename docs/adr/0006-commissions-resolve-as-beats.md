# Commissions resolve as a sequence of Beats

A Commission is not resolved by one roll, and not by a tactical encounter system. It generates a
run of Beats — an ambush, an obstacle, a discovery, a quarrel — each settled by a Check and each
emitting events, with consequences accruing across them.

A single roll cannot produce a story: it yields "succeeded" and leaves the narration layer
nothing to work with, which would quietly defeat the whole point of the game. A tactical system
would produce plenty of story but moves the player's attention onto moment-to-moment combat,
which is a different game from running a Guild. Beats sit between: one Beat is about one
paragraph of the report, and Beats are where a Trait like *Craven* visibly changes what somebody
does.

There is deliberately no combat system in this codebase. That is not an omission.
